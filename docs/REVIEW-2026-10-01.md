Reviewed main at `2d15c3307b4f310fede111ecd34b6265fd09482c` (0.2.1). The core fleet system, expanded progression, art, and Galactic Center route are implemented. All existing pull requests were merged, with no open issues or pull requests at review time. The latest pre-review change was the August 8 asteroid-density curve.

## Correctness fixes in 0.2.2

- **Broken Linux release archive:** the checked-in archive used Windows backslashes. Linux Factorio rejected the mod while returning success for a vanilla save. A deterministic Python builder now produces portable ZIP entries; PowerShell invokes the same builder. Tests require the mod to actually load.
- **Destructive fleet splitting:** cloning destroyed the destination hub, which invalidated the new platform. The split now preserves the starter hub and its settings, clones permanent nonhub entities, verifies the resulting layout, then commits fleet sizes and clears crafting progress. Failed creation or cloning leaves the source unchanged.
- **Other-mod effects lost:** fleet updates replaced the full surface-effect table. Updates now add/remove only the fleet-owned contribution and preserve the engine's percentage precision.
- **Large-fleet dust limited unnecessarily:** the backlog cap also capped production delivered to an empty hub. The cap now applies only to undeliverable overflow.
- **Orbital science blocked by planet requirements:** four dedicated orbital science recipe copies are unlocked by Orbital industry. Only the matching interstellar machines can use them; vanilla recipes and buildings retain their restrictions.
- **Replication rewrote ordinary recycling:** Quality generated reverse recipes that could turn ordinary items back into interstellar dust. Replication recipes now opt out of automatic recycling.
- **Weak merge signatures and misleading remote results:** layout matching includes quality, exact positions, and foundations while ignoring transient entities. Remote operations return failure when no action succeeded. Existing recorded layouts require one explicit blueprint refresh.
- **Force lifecycle:** old force names no longer retain stale progression after removal/recreation, and merged-force progress is preserved.

## Remaining design limits

These are not represented as solved:

1. Cryogenic science consumes coolant inputs that currently need imports. Building more labs, replicators, and drives also requires some planet-built components, so the fleet is not fully self-sufficient yet.
2. The split hub starts empty, while inventories in machines, belts, and fluids are copied. A stock-conserving split needs a defined aggregate-cargo model and further implementation.
3. Scripted relativistic speed/distance remain abstract values; they do not change vanilla platform travel speed. Visual client QA, multiplayer soak testing, and megafleet balancing remain beyond this headless regression pass.

No merge, release publication, or deployment is part of this review.
